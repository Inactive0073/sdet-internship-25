### Инструкция по запуску тестов
Данная инструкция описывает процесс запуска автоматизированных тестов для проекта Yandex Disk API с использованием виртуального окружения Python.

#### Предварительные требования
1. Установленный Python (рекомендуется версия 3.10 или выше).
2. Установленный pip (менеджер пакетов Python).
3. Доступ к командной строке (cmd.exe на Windows)

#### Шаги по запуску тестов
1. **Клонирование репозитория**
   - Склонируйте репозиторий с тестами на ваш локальный компьютер:
     ```
     git clone https://github.com/Inactive0073/sdet-internship-25.git
     cd sdet-internship-25
     ```
2. **Запуск**
    - Для запуска тестов в параллельном режиме используйте скрипт `run_tests_parallel.cmd`:
      ```
      scripts\run_tests_parallel.cmd
      ```
    - Для запуска одиночного теста используйте скрипт `run_tests_single.cmd`:
      ```
      scripts\run_tests_single.cmd
      ```
